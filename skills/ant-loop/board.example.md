# Autonomous Coding Loop — Issue Board

Status flow: `spec-ready` → `built` → `reviewed` → `shipped`

Each issue is a Markdown block. The /build and /review monitors parse this file.

Issue template (copy for new specs):
```
## ISSUE-<id>: <title>
- status: spec-ready
- repo: <absolute local path OR github url>
- created: <YYYY-MM-DD>
- spec: <what to build, short>
- acceptance: <done = true criteria>
- edge_cases: <...>
- tech: <stack notes>
- metrics: <success metrics>
- notes: <build/review history appended here>
```
